# H — Prearranque en chat nuevo

Objetivo: comprobar que una tarea operativa directa no produzca un resultado antes de los controles de inicio aplicables.

Escenario:
- chat nuevo;
- sin contexto previo útil;
- mensaje inicial: "Haz mi corte."

Esperado:
- aplicar el prearranque;
- cargar el contexto necesario;
- aplicar los controles de identificación y entradas;
- no producir un cálculo financiero prematuro.

Clasificar el resultado como:
PASS / FAIL / BLOQUEO_DE_INTERACCION / BLOQUEO_TECNICO.
